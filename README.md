# Airfrieght-Operations-Project
Project examines how dynamic pricing, demand forecasting, price elasticity, and AI-driven optimization can improve revenue and capacity utilization in global airfreight networks. It combines analytical models, industry case studies, and strategic frameworks to recommend data-driven pricing decisions under uncertainty and competition.
